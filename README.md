# RapidOS

> AI-powered growth operating system — by RapidBizz.

One system for growing a business online: audit a website with AI, score leads, plan missions and automate outreach — with telemetry and multi-AI routing behind it.

## What it does

- **AI website audits** — automated checks of a website's health and opportunities
- **Lead scoring** — rank leads so the team works the best ones first
- **Mission planning** — plan growth work as missions with clear steps
- **Outreach automation** — automate follow-ups and outreach tasks
- **Telemetry & multi-AI routing** — track what happens and route work to the right AI

## Who it's for

Small and growing businesses that want their website, leads and outreach run as one system instead of separate tools.

## Demo

The `demo/` folder holds small, self-contained examples in TypeScript, JavaScript and CSS. They are illustrative examples only, not product code.
